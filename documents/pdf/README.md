## 🖨️ How to Create PDFs

### Method 1: Browser Print to PDF (Recommended)
1. Open any HTML file in your web browser
2. Press **Ctrl+P** (or **Cmd+P** on Mac)
3. Select **"Save as PDF"** as the destination
4. Adjust settings if needed:
   - Paper size: A4
   - Margins: 0.5cm or 0.25in
   - Layout: Portrait
   - Enable background graphics
5. Click **"Save"** to create the PDF

### Method 2: Batch Opening (Windows)
1. Run the `open-all-for-pdf.bat` script from the parent directory
2. Each file will open in a new browser tab
3. Follow the print-to-pdf process for each file
4. Save PDFs with the same names as the HTML files

### Method 3: Online Converters
You can also use online HTML to PDF converters:
- Smallpdf.com
- ILovePDF.com
- PDF24.org
- Adobe PDF Converter
